# Security policy

## Supported versions
Security fixes go into the latest release. Please update before reporting.

## Reporting a vulnerability
Please don't report security problems in public issues, pull requests or discussions. Instead:

- Use **[Report a vulnerability](https://github.com/XNyetok/Jambul/security/advisories/new)** on the repository's Security tab, which keeps the report private, or
- Email **debi@elysiumx.org**.

Include what you found, how to reproduce it, and which version and macOS release you used. You'll get a reply within 7 days. Once a fix is ready, we'll agree with you on when to publish it, and credit you if you'd like.

## What counts
- Anything that lets Jambul be used to run code, gain privileges, or read or change data it shouldn't.
- Problems in how releases are built or published.
- **A secret or personal data found in this repository or its history.** Report it privately too, so it can be removed before it spreads.
